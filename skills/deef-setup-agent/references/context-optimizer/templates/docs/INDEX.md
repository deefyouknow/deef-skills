# Context Index

Template guidance: use an index only when no existing authority already routes readers effectively. Do not create companion files merely to populate it.

Replace this guidance with task-to-path routes derived from the target project. Each route should name the task area, the entry file to open first, relevant deeper references, and the source of validation commands. Include only existing paths, resolved relative to the resulting index. Link to existing architecture, decisions, or continuation state only when relevant.

The resulting index should tell readers what to open for their task and what to read only when needed. Do not ask readers to load every linked document.
